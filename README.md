# Music and Mental Health Analysis

A compact exploratory analysis of a self-reported survey on listening habits and mental health measures.

## Contents

- `notebooks/music_and_mental_health_analysis.ipynb` — cleaning, data checks and visualisations
- `data/Impact_music_mental_health.csv` — supplied survey data
- `images/` — charts generated by the notebook

## Approach

The notebook removes observations outside the selected age, listening-time and BPM limits, removes fields not used in the analysis, and fills the remaining missing values with simple, documented rules. It then explores age, music frequency, listening time, reported anxiety and correlations among numeric fields.

The responses are self-reported. Results are descriptive and should not be read as clinical or causal evidence.

## Run locally

```bash
pip install -r requirements.txt
jupyter notebook notebooks/music_and_mental_health_analysis.ipynb
```
